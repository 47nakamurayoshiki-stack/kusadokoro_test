## セクション背景について
セクションごとに背景色を変えています。
`bg-craftsman.jpg` と `bg-plan.jpg` は背景に薄く写真を重ねる仕様（CSS側で白いオーバーレイを掛けています）なので、
同じファイル名で画像を置き換えるだけで自然になじみます。
